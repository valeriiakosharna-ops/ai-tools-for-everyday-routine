# ШІ для щоденних справ

Український навчальний сайт про використання інструментів ШІ у повсякденних задачах. Eleventy збирає шаблони та навчальні дані у статичні HTML-сторінки. Сервер, база даних та API-ключі для роботи сайту не потрібні.

## Що вже є

- Головна навігаційна сторінка.
- Таксономія: чотири способи взаємодії, шість інструментів, приклади, можливості, обмеження та офіційні джерела.
- Пошук і фільтрація карток, порівняльна таблиця та вибір інструмента за задачею.
- Практикум: виконайте п’ять коротких вправ із ChatGPT, Gemini, NotebookLM та Claude, скопіюйте готові запити й перевірте результат. За бажанням пройдіть вбудовану навчальну симуляцію Claude Code / Codex: прочитайте HTML, зіставте різницю, застосуйте зміну заголовка й перевірте чотири умови у браузері. Без JavaScript зіставте приклади «до / після» вручну. Демо не підключає справжніх агентів і не запускає збірку проєкту.
- Завантажте два навчальні документи для NotebookLM. Відстежуйте виконання вправ у своєму браузері; позначки зберігаються локально, без надсилання на сервер. Якщо сховище недоступне, користуйтеся позначками в поточній вкладці.
- Дізнайтеся про майбутні тренажери: токени, контекстна пам’ять, векторна БД. Самі симуляції ще не реалізовані.
- Адаптивна верстка, клавіатурна навігація, читання матеріалів без JavaScript.

## Локальний запуск

Потрібен Node.js 22 LTS та npm. Версію Node також задано в `.nvmrc`.

```sh
npm ci
npm start
```

Команда запускає локальний сервер на порту 8080 і перебудовує сайт після змін.

```sh
npm run check
```

Збирає сайт у `_site/` та перевіряє сторінки, локальні посилання, якорі й наявність навчального матеріалу. Згенеровані файли та `node_modules/` не зберігаються у Git.

## Публікація на GitHub Pages

1. Додайте зміни до репозиторію та відправте їх у `main`.
2. У репозиторії відкрийте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Для зміни цього налаштування потрібні права адміністратора репозиторію.
3. Запустіть **Actions → Build and deploy Pages → Run workflow**, якщо збірка після push ще не публікувалася.
4. Після успішного `deploy` адреса буде в результатах workflow та в **Settings → Pages**.

Для поточного репозиторію стандартна адреса — `https://valeriiakosharna-ops.github.io/ai-tools-for-everyday-routine/`. Вона запрацює після увімкнення Pages та успішної публікації; створення файлів локально не публікує сайт.

Workflow `.github/workflows/pages.yml` встановлює залежності через `npm ci`, збирає й перевіряє HTML, завантажує артефакт і публікує його через офіційні Pages actions. Pull request проходить збірку та перевірки без публікації. `GITHUB_TOKEN` створюється автоматично; окремий токен чи секрет додавати не потрібно.

Префікс посилань визначається з назви репозиторію. Для перевірки такої збірки локально:

```sh
SITE_PATH_PREFIX=/ai-tools-for-everyday-routine/ npm run check
```

Якщо додаєте власний домен, змініть префікс на `/` у кроці `Detect Pages path` та налаштуйте домен у GitHub Pages.

## Додавання матеріалів

| Файл | Призначення |
| --- | --- |
| `src/index.njk` | Головна та навігаційні картки |
| `src/taxonomy.njk` | Структура навчальної сторінки |
| `src/_data/taxonomy.json` | Описи, приклади, обмеження та джерела інструментів |
| `src/practice.njk` | Структура практикуму та додаткова демонстрація агента |
| `src/_data/practice.json` | П’ять вправ: кроки, запити, результати та самоперевірка |
| `src/assets/practice.js` | Копіювання запитів і локальні позначки виконання |
| `src/assets/practice.css` | Адаптивне оформлення практикуму |
| `src/_includes/agent-demo.njk` | Приклад HTML, різниця та кроки вбудованого демо |
| `src/assets/agent-demo.js` | Застосування зміни, попередній перегляд і перевірка навчального HTML |
| `src/assets/agent-demo.css` | Адаптивне оформлення демо |
| `src/assets/materials/` | Вигадані навчальні джерела для вправи з NotebookLM |
| `src/simulators.njk` | Майбутній розділ тренажерів |
| `src/_includes/base.njk` | Спільні шапка, навігація та підвал |
| `src/assets/styles.css` | Стилі й брендова палітра |
| `src/assets/site.js` | Пошук, фільтри, вибір задачі та мобільне меню |
| `src/assets/logo.svg` | Векторне відтворення наданого логотипа |

Брендова палітра: `#00A6EB`, `#E60036`, `#81D0F4`, `#EF958C`, `#2A668E`, `#937C8A`, `#302A40`, `#951B3C`. Логотип відтворено у SVG за наданим зображенням; оригінальний векторний файл можна покласти замість `src/assets/logo.svg`.

Текст таксономії адаптовано з наданого матеріалу: прибрано технічні артефакти вставки й тимчасові посилання на зображення, назву спеціалізованого продукту уточнено як NotebookLM. Можливості продуктів змінюються — перевіряйте офіційну документацію під час оновлення матеріалів.

Під час оновлення сторінок звертайтеся безпосередньо до читача на «ви». Описуйте задачі через «попросіть», «перевірте», «ваш проєкт», а готові запити — від першої особи. Не описуйте дії читача через сторонні ролі. Для виконання вправ відкривайте відповідні зовнішні сервіси; сайт не запускає ШІ та не оцінює ваші відповіді автоматично.
